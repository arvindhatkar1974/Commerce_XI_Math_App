# Commerce XI Maths App

A browser-based practice application for Standard XI Commerce Mathematics & Statistics.

## Available content

- Part 1, Unit 1 theory and exercises
- Five prepared papers and a date-seeded Surprise Test
- Five minutes per question
- +2 for a correct answer and -1 for an incorrect answer
- Detailed answer PDFs and a Unit 1 study guide
- Results stored locally in the student's browser

## Public site

After GitHub Pages is enabled, the app will be available at:

https://arvindhatkar1974.github.io/Commerce_XI_Math_App/

## Local use

Run:

```powershell
npm start
```

Then open http://127.0.0.1:4187/.

## Privacy and storage

The app has no server-side student accounts. Attempts and results are stored in browser localStorage on each student's device.
